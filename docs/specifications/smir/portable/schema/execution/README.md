# Execution schema package

The current compiler candidate is candidate.json, generated by
`tools/smir-format/execution/candidate/schema_build.py`. It defines exact ordered
roots execution_types/1, execution_functions/3 and execution_exceptions/8, every
operation/terminator variant and typed live-value/progress records. All record
fields are closed; physical parsing is distinct from type/CFG/ABI/link admission.

| File | Interface/status |
|---|---|
| candidate.json | coherent0.2/profile2 compiler candidate; shared decisions/combined freeze are integrator-owned |
| records.json | preserved isolated integer_core_draft_v1 |
| floating.json | preserved rational FP request interface, not candidate executable roots |
| exceptions.json | preserved separate logical two-phase protocol draft |
| types.json | preserved standalone extended structural type graph witness |
| raw-bits.json | preserved standalone per-bit shadow witness |
| sources.json | pinned primary identity/license/checksum/archive |

Candidate wire.py interprets the candidate metaschema independently of the shared
root codec. Type/operation/SSA/region checks are in candidate/verify.py; actual
ABI/runtime metadata binds through candidate/context.py and bindings.py. Common
records must match byte-for-byte when schemas are merged. Qualified refs select
explicit consumer namespaces; wrong-table equal numeric IDs reject. Unknown
variants, fields, options, attributes and malformed constants reject rather than
becoming generic opaque extension payloads.

Live records do not grant registry authority. absolute_range adds canonical
upper_is_limit with upper0 for2^64 and explicit empty; range-only taint can have
origin.object=None/generation0 without granting provenance. All addresses remain u64;
known tombstones preserve provenance without dereference permission. Exact issued
snapshot handoff, generations, thread/activation and complete runtime admission
are separately required. See ../../02-execution.md and ../../05-encoding.md for
semantics, assumptions, resource limits, evidence boundaries and primary sources.
