# Finite scalar source/body alignment reference

This package checks caller-provided, manually authored SMIR against actual issued Clang typed source observations and a separate actual source-condition observation. It emits no SMIR, LLVM module or machine code. A successful finite_alignment_checked result is a CONDITIONAL VALUE-BODY relation for one selected scalar function over the SAME defined parameter bit patterns. It is not source Nominal/FullFn/calling-boundary equivalence, complete C++ source proof, portable ABI identity, executable admission or a runtime fact. Every authority/admission/full-source flag is false.

The old typed-AST witness8506 is unchanged. Actual original source/target/options/library/config/declaration/type/node/CFG namespaces must match the full independently observed condition-native raw graph, not just local IDs. Conditions include real function/redeclaration/parameter attributes, constexpr/no-return/method/defaults, original unsugared builtin integer/overflow-behavior types, C++23/default-overflow settings and warning count. Missing conditions are unavailable. Unknown attribute warnings refuse. The new condition observer conservatively excludes every source byte spelling _Pragma or __pragma before parsing, including comments/string contents, so source diagnostic suppression is outside the profile. Existing #/%:/??=/line-splice exclusions also apply. This is a lexical input profile, not inference of semantics from spelling.

The single-block profile covers exact literals, parameters, unsigned +,-,*,&,|,^, and integer casts with actual source signedness and exact width. Parentheses, same-width casts, NoOp and parameter LValueToRValue alias the identical SSA. All AST expression nodes and all SMIR operations/results must be mapped exhaustively; no dead operation, folded substitute, guessed copy/freeze or operand reordering is ignored. Signed binary arithmetic/bitwise, all other operators, memory/calls/CFG/lifecycle/source observers and nonempty embedded source-contract tables explicitly refuse. Ordinary SSA/type IDs retain fullu32 includingFFFFFFFF; source/AST/function IDs exclude that sentinel.

The .cpp files and explicit mapping rows are independent inputs. The .roots.json files are MANUALLY AUTHORED full-root fixture recipes based on preserved ordinary-scalar platform/ABI roots. Their pre-seal identity is not a valid new module identity. The .sealed-roots.json and .smo files reflect the existing codec's genuine fixture custody seal. scalar_fixture_support.py contains fixture-only explicit body rows and existing codec sealing; it NEVER consumes AST/LLVM input and is never imported by the checker. scalar_mapping_witness.py supplies reviewed explicit mappings and only reads/prints during normal witness execution. Production scalar_alignment.py has no encoder or file-write API.

Fixtures one/two prove the actual literal1/2 distinction. subtract/add/xor and unsigned-casts/signed-casts exercise exact operand order and trunc/zext/sext. pragma-suppressed.cpp is the preserved old underqualified-profile counter: old condition-native admitted warning0/hasAttrsfalse; new native must reject it. No C++ value mismatch or runtime admission was inferred from the old counter. New negative tests validate genuine full-v3 bodies before rejecting wrong literal/order/sign/SSA/return or extra operation. They also cover source conditions, forged/copy/replaced witnesses, stale metadata, ledger identity, fullu32 values/types, exact/one-less before real body factory, both CLI modes and original input afterguards.

CLI scalar_alignment.py requires --source, --ast-oracle, --condition-oracle, --module, --mapping and --budget. Budget JSON is the existing closed canonical SourceQueryBudget bootstrap. All three caller files are bounded/read again before output. Every reference result remains unbound and nonexecutable. Native condition oracle is built with build_scalar_conditions.py --llvm PINNED_CHECKOUT --output FRESH_OUTSIDE_BOTH_CHECKOUTS; real source/compiler/library/header/builder inputs are guarded. No stale recipe or fallback/native skip counts as a pass. Use explicit SCALAR_AST_ORACLE/SCALAR_CONDITION_ORACLE for native tests; pure tests need neither. Installed paths derive from repository layout; owncoord qualification uses explicit SCALAR_REFERENCE_PROJECT/SCALAR_REFERENCE_SCHEMA/SCALAR_REFERENCE_FIXTURES overrides.

Assumptions and source-backed finite mathematics are in the exact reviewed01..06 proposals and handoff. Logical work/edge/payload accounting is not processor/RSS or native frontend complexity proof; native source/output/time caps apply. No original owner/root/stamp is projected or rewritten by the checker. No private S/J/lifetime/ticket/registry or guest interpreter/JIT execution is issued.
