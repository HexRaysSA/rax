# Typed source semantic observations (draft)

These fixtures exercise a separate actual Clang AST observation tool. The installed source-events reference revision 1 is unchanged. No fixture is executable SMIR or an admission proof.

`one.cpp` and `two.cpp` differ only in an aggregate initializer literal. The old observation payload loses that distinction except for the source hash. The new observation preserves exact 32-bit APInt patterns `00000001` and `00000002`, with canonical type and operand edges. This closes that specific observation loss. It does not establish original-source to SMIR-body correspondence.

`integers.cpp` covers zero extension into the compiler's 128-bit integer extension, exact 64-bit and 32-bit all-one literals, negative syntax as a unary operator, explicit/implicit casts, and ordered binary operands. No actual 128-bit APInt literal is claimed; the 128-bit observation is a type/cast. `boundaries.cpp` covers zero, bool, void return and qualified pointers. `construct.cpp` observes an actual declared constructor and argument identity, without a user constructor body. `calls.cpp` and `locals.cpp` cover direct calls and aggregate member identities. No hosted library, portable ABI, source execution or runtime capability is inferred.

`one.raw.json` is an actual native observation, independently checked by the Python graph/schema validator. Its original native receipt inputs and hashes are in `provenance.json`. A report supplied by a caller is never an original witness: `match_original` validates it and reruns the actual native observer before comparing the entire report. `resolve` accepts a closed `(source_sha256,function,node)` origin reference only against the same witness ledger. These origins refer to AST nodes, not LLVM/SMIR operations.

The finite supported body nodes are: integer/bool literals, declaration/member references, the closed cast set, constructor calls, semantic initializer lists, builtin binary/unary expressions, direct calls, compounds, return, local declarations, parentheses, cleanup/materialization/bind wrappers, implicit value initialization and null statements. All other encountered body nodes are explicitly unavailable. If/loops/EH, floating point, arrays, unions, bases, dynamic classes, templates, lambdas, indirect calls, global/static/TLS variables and user constructor/destructor bodies are outside this draft. AST/CFG cleanup observations do not prove lifecycle or exception completeness.

The target is the fixed stock Clang x86_64-unknown-linux-gnu observation target, with 8-bit bytes, 64-bit pointers/long and little-endian memory. This is not a portable SMIR ABI plan. Integer `bits_hex` is a most-significant-digit-first hexadecimal APInt pattern padded to ceil(width/4), not a memory byte string. Negative integer source syntax retains a separate unary minus node; it is not folded into the positive literal's pattern.

Native frontend complexity is controlled by fixed source/AST/type/CFG/output/time bounds, not proven by the logical Python ledger. All Python capture, schema/graph walks, native stream bytes and guarded input hashes charge the actual canonical SourceQueryBudget. Reports retain that same ledger and remain deeply immutable/unbound with runtime_authority=false, source_fact_authority=false and executable=false.
