# Original typed Journal observer witnesses

The fixture is a newly authored legal INLINE partial-factory/caller graph. Both
ordinary functions return only their original pointer. Callee J20 is an actual
journal_begin result bound after that helper, retained in source return metadata;
caller J2 is defined by the actual observer after once-only normal adoption. Both
source scopes close at explicit retained returns. No physical Fn Journal slot,
source-object double bind, caller rebind or fabricated source/runtime fact exists.
The baseline inputs and exact fixture hashes are in manifest.json.

Run from the project root:

    python3 -B tools/smir-format/execution/test_candidate_source_observer.py
    python3 -B -O tools/smir-format/execution/test_candidate_source_observer.py
    python3 -B docs/specifications/smir/portable/conformance/execution/source-observer/generate_fixtures.py --check

The generator authors only this package's four data files using the existing
codec. It validates actual original-v3 ABI/body custody; it is not an emitter or
source legality proof. The checker never uses generator output as issuer truth.
Nonwriting reproduction compares every data byte, including the manifest.

Each complete witness uses an isolated process, actual RootContext.from_module,
real ABI/body/Types and one canonical constructor/query SourceQueryBudget. The
fixed predicate defines a Journal SSA and collects original coordinates while
keeping full v3 roots, source stamp and all false authority fields. The runtime
role's separately qualified checker performs actual embedded source/adoption
constraints and source alpha comparison; this package does not fake that pass.

Coverage includes actual full-root/owner/stamp/budget custody, immutable observed
coordinates, ordinary/source same-numeric IDs, full-u32 result/type/block bounds,
exact opcode/arity/Journal/source-ID rejection, caller type-oracle refusal,
actual SSA duplicate/use/dominance, actual scope freshness at PRE, default/true
path modes, SourceRegistry/Machine/public-v2 execution refusal and quota before
actual type lookup or output construction. The undefined-S direct helper case is
an explicitly malformed abstract-boundary input; it is not a public source
positive. Stale-S uses a genuine structurally encoded and typed original module.

The ordinary SSAFFFFFFFF positive checks typed-body representation with a terminal
source outcome, because the initial raw source Journal link cannot represent that
SSA in its nonsentinel field. It does not claim that full source relation accepts
that terminal partial-object metadata. Physical type/blockFFFFFFFF cases preserve
existing execution domains without changing any source ID range. Same-numeric
ordinary J100 and source S100 remain separate namespaces and never overwrite one
another. Alpha normalization may rewrite only S/adoption fields, not ordinary J.

Resource migration is explicit: all-block/operation preflight4work/1edge per visit
applies in default mode too; actual observer PRE checks add8work/1edge/32copied
payload bytes. Historical ledger counts are not repinned. Collector/predicate
node/key/string/type/output work is charged before work using the same actual B.
Body source afterguards run after collection. These are logical units, not a
processor instruction, elapsed-time or RSS proof. Path states remain finite and
may be exponential, with the existing65536-state rejection bound.

Assumption Register:

| ID | Dependent result | Falsification probe |
|---|---|---|
| O1 typed Journal does not issue actual J | nonadmission | actual Machine/registry/verify_execution refusal; all false fields |
| O2 source IDs have distinct namespaces | coordinate/path/alpha relation | same numeric J/S, wrong S/adoption/bool/sentinel, ordinary SSA changes |
| O3 actual original factories/stamp/B remain | compiler reference custody | changed B, edited ABI flag, caller oracle, source mutation during collection |
| O4 finite normal receiver profile is partial | source association | stale/undefined PRE, missing/wrong binds/attach/return/phase, unsupported richer cases |
| O5 source alpha preserves ordinary SSA | source identity relation | joint S/adoption renaming versus changed ordinary result/body |
| O6 real scans/copies consume cumulative quota | resource envelope | zero/exact/one-less and before-type/output controls; old regressions at new costs |

High: full source language/body/phase/lifecycle/EH/actual Journal outcome, epoch,
generation/actor/lease and runtime facade issuance remain incomplete. Medium:
strict one-call/create/always/inline partial-factory source profile and abstract
path limits. Low: inspection coordinates are not transferable source facts.
No native execution, production admission or compiler freeze follows.

The runtime source profile is exactly one callee block with journal_begin then
ordinary return, and one caller block with call(index0), observer(index1), then
ordinary return. Prelude/extra-block/intervening/post-observer operations are
explicit source-profile unavailable even when their typed bodies are valid.
The supported source relation is a selected function plus its supported closure;
valid unreachable function bodies remain outside comparison after both complete
original modules are independently validated. All fields of selected functions
remain observable, with only observer S/adoption IDs jointly alpha-renamed.
