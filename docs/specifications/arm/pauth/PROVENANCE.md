from the pinned QEMU C functions, with no RAX-generated expected values. It

producers. The same script checks `pc`, `lr`, `sp`, `fp`, `nonce`, and `uctx`
string discriminators with the host Clang arm64e builtins. XNU primary sources,
including kernel pmap failure poisoning, are retained under
`docs/specifications/darwin/xnu-12377.121.6/` with their own checksum manifest
and provenance record. Apple's private hardware key diversification is not
part of these virtual QARMA fixtures.
