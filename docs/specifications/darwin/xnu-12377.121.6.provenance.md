## Use in RAX

The Darwin personality (`src/user/darwin/`) and the Mach-O parser
(`src/user/image/macho/`) implement the XNU user-space ABI for emulated
macOS programs. These files define the behavior they reproduce:

| Area | Files |
|---|---|
| Fat files: table validation and slice grading | `bsd/kern/mach_fat.c`, `bsd/dev/arm/kern_machdep.c`, `bsd/dev/i386/kern_machdep.c` |
| Mach-O acceptance, segment mapping, entry and stack selection, `dyld` loading | `bsd/kern/mach_loader.c`, `bsd/kern/mach_loader.h`, `bsd/kern/kern_exec.c` (`exec_fat_imgact`, `exec_mach_imgact`, `load_return_to_errno`, `create_unix_stack`) |
| Mach-O format constants | `EXTERNAL_HEADERS/mach-o/loader.h`, `EXTERNAL_HEADERS/mach-o/fat.h`, `osfmk/mach/machine.h` |
| Initial thread state (`thread_userstack`, `thread_entrypoint`) | `osfmk/i386/bsd_i386.c`, `osfmk/arm64/status.c`, `osfmk/mach/{i386,arm}/thread_status.h`, `osfmk/mach/{i386,arm}/_structs.h` |
| Default stacks and stack limits | `osfmk/mach/i386/vm_param.h` (`VM_USRSTACK64`), `bsd/arm/vmparam.h`, `bsd/i386/vmparam.h` (`USRSTACK64`, `MAXSSIZ`, `DFLSSIZ`) |
| Error numbers | `bsd/sys/errno.h` |
