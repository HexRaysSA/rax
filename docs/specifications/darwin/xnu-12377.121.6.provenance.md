Paths under `xnu-12377.121.6/` mirror the XNU tree. The files are reference
inputs; do not reformat or edit them. To move to a newer release, import a
complete new `xnu-<version>/` tree with its own provenance record.

The host this work was developed on runs a newer, unpublished kernel
(`xnu-13432`, macOS 27.2). Where its behavior visibly differs from this
release, the difference is recorded next to the implementation rather than
inferred from these files.
